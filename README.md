# Claude Hub

倬的 Claude 操作手冊。忘記步驟時來這裡查：

- **每日 SOP**：`#開工` → 開發 → `#更新` → `#收工`
- **A（家）↔ B（學校）接續**：靠 GitHub 與 `PROJECT_STATUS.md` 交接紀錄
- **指令集**：# 自訂指令、Claude Code、Git、dotenvx、PowerShell
- **環境變數**：dotenvx 共用金鑰加密現況與新專案設定 SOP
- **檔案位置**：每個技能、腳本、設定檔放在哪裡

## 本機預覽

```powershell
npm.cmd install
npm.cmd run dev
```

內容在 `docs/`，每頁一個 Markdown 檔。
